# Contributing

1. Create a focused branch.
2. Keep collection deterministic; AI must not enter the default acquisition or ranking path.
3. Add minimal source fixtures instead of copying full web pages.
4. Run the Python suite and JavaScript syntax check.
5. Never commit API keys, databases, logs, cookies, or generated posters.

New official sources must use allow-listed HTTPS, document their terms/license, preserve the last trusted value on parser drift, and include parser tests.
